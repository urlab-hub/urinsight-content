# Pretendard

- 사용 패키지: `pretendard@1.3.9` (pnpm dependency)
- 사용 파일: `node_modules/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`
- 공식 저장소: https://github.com/orioncactus/pretendard
- 공식 라이선스: https://github.com/orioncactus/pretendard/blob/main/LICENSE
- 라이선스: SIL Open Font License 1.1
- 확인일: 2026-09-16

공식 문서상 상업적 사용, 임베딩, 수정 및 재배포가 허용됩니다. 폰트 자체 단독 판매는 허용되지 않으며, 재배포 시 저작권 및 OFL 고지를 유지해야 합니다. 폰트 이름 관련 reserved name 조건도 적용됩니다. 생성 이미지 자체에는 OFL 적용 의무가 없습니다.

폰트 바이너리는 Git에 추가하지 않습니다. pnpm lockfile로 배포 패키지를 고정하고 node_modules에서 읽습니다. npm 패키지에는 별도 LICENSE 파일이 없으므로 v1.3.9 공식 태그의 원문을 [PRETENDARD-LICENSE.txt](PRETENDARD-LICENSE.txt)에 보존했습니다. 폰트를 재배포할 때 이 저작권·라이선스 고지도 함께 보존해야 합니다. 렌더링은 로컬 폰트 data URI를 사용하므로 CDN 가용성에 의존하지 않습니다.
